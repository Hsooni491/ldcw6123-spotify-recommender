# Spotify Music Recommendation

A small C++ program that recommends songs, based on how Spotify works.
This is Part 2 of our LDCW6123 group project.

## How it works
First you pick Free or Premium. Then you pick a genre (Pop, Hip-Hop, Lo-Fi
or Rock), choose a song from the list, and it shows the artist and a short
description. Free users see an ad message at the end, Premium users don't.
If you type something wrong, like a letter, it asks again.

## Run it
g++ -Wall main.cpp -o spotify
./spotify
